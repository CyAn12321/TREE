# Team workflow

- Keep `main` runnable and stable.
- Create feature branches such as `feature/core-generation`,
  `feature/foliage-season`, `feature/weather-anim`, and
  `feature/ui-integration`.
- Test changes in Maya before opening a pull request.
- Request at least one teammate review before merging.
- Avoid committing Maya autosave files, caches, or generated output.
