# 器官资产来源

本目录收录从 **Kenney Nature Kit 2.1** 中筛选的叶片与花朵 OBJ 模型，供课程项目在 Maya 中实例化。

- 来源：https://kenney.nl/assets/nature-kit
- 作者：Kenney
- 许可证：Creative Commons Zero 1.0（CC0-1.0）
- 原始许可证文本：`LICENSE_KENNEY_CC0.txt`
- 获取日期：2026-07-20

项目保留了 OBJ/MTL 原文件名。`catalog.json` 为本项目新增的语义目录，定义器官类型、季节状态、选择权重和归一化缩放。模型使用 +Y 作为生长方向，并在加载时统一归一化高度与基部枢轴。

虽然 CC0 不要求署名，项目文档和界面仍建议标注 “Organ assets: Kenney Nature Kit (CC0)”。
