# 四季循环动画

## Maya 操作

1. 运行 `D:\未来创新设计\TREE\launcher.py`。
2. 生成一棵树，并选中树根或树上的任意对象。
3. 在 `SEASONAL CYCLE ANIMATION` 面板中设置：
   - `Cycle Start`：循环开始帧，默认 1。
   - `Frames per Season`：每个季节的帧数，默认 240。
   - `Transition Frames`：季节交界处用于落叶/落花的帧数，默认 60。
4. 在 `WIND ANIMATION` 面板中设置风强度、风向、落叶和落花强度。
5. 点击 `Create Seasonal Cycle Animation`。
6. 从循环开始帧播放。默认总范围为 1–960 帧：春、夏、秋、冬各 240 帧。

## 实现方式

- 树干和树枝只生成一次。
- 四个季节分别生成独立 foliage 图层，并由可见性关键帧切换。
- 一个共享的 bend deformer 作用于树枝和四个季节图层，保证风向一致。
- 春到夏、夏到秋、秋到冬的交界处使用同源叶片/花瓣实例生成落叶和落花。
- 点击 `Remove Seasonal Cycle` 会删除四季图层和循环动画，并恢复当前 UI 选定的单季节 foliage。

四季循环会同时保留四套 foliage 网格，因此复杂树种可能占用较多 Maya 内存；如果播放卡顿，可以降低叶片、花朵密度或每季节帧数。
